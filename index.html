Paketpost Aerial Vision

Full-stack proptech application · 2024

MongoDB Express React Node.js Azure Three.js IFC.js
View on GitHub ← All Projects

A full-stack proptech platform built around a real urban regeneration brief: the redevelopment of Munich's historic Paketpost depot into a mixed-use quarter. The platform was designed to serve people at different stages of their relationship with the building, from prospective buyers and renters through to existing residents.

For people exploring whether to buy or rent, the application offers a property discovery flow. Users fill out a form describing their ideal unit, and the platform filters available properties and locates them on a custom-built 3D viewer that fuses a GIS masterplan with a BIM model, so you can see exactly where in the development a shortlisted property sits. For existing residents, a maintenance feature gives each person access to the BIM model of their own flat in the browser. They can click on individual building elements and report issues directly against them.

The frontend (React + Vite) delivers a scroll-driven landing experience presenting the architectural concept across five expandable design chapters covering structural innovation, cultural identity, green strategy, and the facade logic of the two signature towers. The IFC viewer, built with Three.js and IFC.js, allows visitors to explore the building model interactively without any plugin or download.

The backend (Node.js + Express) exposes a REST API for contact submissions, user authentication, and a protected admin dashboard for property and maintenance record management, all persisted in MongoDB Atlas. The full stack is containerised with Docker and deployed on Azure Web Apps, with the frontend served through Nginx.

My Role

I was responsible for the flat maintenance feature, the full-stack architecture of the web application, and the Azure deployment. The maintenance tool involved building the in-browser BIM viewer that lets residents interact with the IFC model of their flat, select individual elements, and submit issue reports linked to those elements.

Working on this project sharpened my appreciation for how much practical value lives in making BIM data accessible to non-architects. The people who will never open Revit are often the ones whose daily lives are most shaped by the buildings those models describe. It also gave me a much clearer understanding of how rich the semantic information inside an IFC file actually is, once you build something that lets you query it.
